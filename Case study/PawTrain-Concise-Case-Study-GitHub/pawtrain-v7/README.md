# PawTrain UX Case Study

A concise, responsive UX/UI case study built with semantic HTML, separate CSS and JavaScript, and the original supplied PawTrain screens.

## Structure

- `index.html` — case study content
- `css/style.css` — design tokens, layout, responsive styles and motion
- `js/main.js` — mobile navigation and scroll-reveal interactions
- `assets/screens/` — the eight supplied app screens and supplied design-system board

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server.

## Deploy to GitHub Pages

1. Push the project contents to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your main branch and `/ (root)`.
4. Save and wait for the deployment URL.

## Design constraints

- Inter font family
- Minimum authored font size: 12px
- 8-point spacing rhythm for layout
- Dark visual direction from the supplied portfolio CSS
- Accent: `#FFF700`; background: `#111111`
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support

The case study does not claim usability-test outcomes or measured business results that were not supplied.

Files:
- pawtrain-case-study.html
- pawtrain-case-study.css
- assets/ (the supplied real UI screenshots and design system board)

How to add to your existing GitHub portfolio:
1. Copy pawtrain-case-study.html and pawtrain-case-study.css into the same folder as index.html, work.html, style.css, main.js.
2. Copy the included assets folder into the portfolio root (merge with your existing assets folder if one already exists; don't overwrite files with the same names unless intended).
3. In work.html, find the PawTrain card's:
   <a href="#" class="case-link">View case study ↗</a>
   Change it to:
   <a href="pawtrain-case-study.html" class="case-link">View case study ↗</a>
4. Commit and push your changes to GitHub; GitHub Pages will redeploy.

Notes:
- The case study is a separate page and uses isolated CSS, so it does not change the portfolio's existing style.css.
- It uses the supplied screen images, design system board, and a cream/green editorial style inspired by your case-study reference.
- The reference image is included in assets only for comparison; it is not shown on the page.
- Research section wording is framed as design synthesis, not invented statistics. No launch metrics were supplied.
